# llemonAI Bare Acts

Central and state Acts from India Code, as PDFs you can read and mark up, on Windows, Android and macOS.

**Not a government app.** llemonAI Bare Acts is made by llemonAI and is not connected with, or endorsed by, the Government of India, any state government or India Code. Every Act is India Code's own PDF from [India Code](https://indiacode.gov.in), the Government of India's public database of laws, downloaded as a web browser would download it and shown unchanged: nothing is retyped, summarised or generated. India Code can take some time to include recent amendments: check the official Gazette before relying on a text. Nothing in the app is legal advice.

This repository holds the app's installers only. Details and screenshots: [llemonai.in/bare-acts.html](https://llemonai.in/bare-acts.html).

## Download

Get the files from the [latest release](../../releases/latest):

| System | File |
|---|---|
| Windows 10 and 11 (64-bit) | `llemonAI-Bare-Acts-1.0.1.exe` (runs as is, no installer) |
| Android 8 and later | `llemonAI-Bare-Acts-1.0.1-android.apk` |
| macOS 12 and later (Apple Silicon and Intel) | `llemonAI-Bare-Acts-1.0.1-macos.dmg` (or the `.zip`) |

`SHA256SUMS-1.0.1.txt` lists each file's SHA-256 checksum.

**macOS, first launch:** the app is not notarised, so macOS stops it the first time. Open **System Settings > Privacy & Security**, scroll down and click **Open Anyway** next to llemonAI Bare Acts.

## What it does

- Every central Act on India Code, the Constitution of India, and the repealed IPC, CrPC, Indian Evidence Act and Income-tax Act, 1961.
- State Acts for every state and union territory: pick the state once.
- Highlight, underline, pen and notes, kept with each Act automatically. Search inside an Act.
- An Act you open stays on your device and opens later without the internet. Once a week the app checks India Code for newer texts.

## Updates

In the app, **About → Check for updates** installs new versions from this repository's releases, after checking each file against its published SHA-256 checksum.

## Privacy

No account, no ads, no tracking. The app talks to indiacode.gov.in for the Acts, and to GitHub only when you check for updates. Your Acts and notes stay on your device. [Privacy policy](https://llemonai.in/bare-acts-privacy.html).
